# ① 단계 테스트: 음성 → 텍스트 (STT / Whisper)

목표: 한국어 발화를 Xavier NX에서 **정확하고 빠르게 텍스트로 변환**한다. Jetson을 쓰는 핵심 이유 중 하나이므로, 이 단계는 CUDA 사용 여부를 반드시 확인한다.

## 모델 선택

| 모델 | 한국어 정확도 | 속도 | 판단 |
| --- | --- | --- | --- |
| tiny/base | 낮음 | 빠름 | 한국어 핵심어 오인식이 많으면 부적합 |
| **small** | 양호 | 빠름 | 기본 선택 |
| medium | 더 좋음 | 느림 | small 정확도가 부족할 때만 |

기본은 **Whisper small**이다. 정확도가 부족하면 medium으로 올리고, 속도가 부족하면 모델을 키우기 전에 CUDA 빌드와 전원/쿨링을 먼저 확인한다.

## 경로 A: whisper.cpp + CUDA (권장)

Jetson에서는 Python 패키지 호환 문제를 줄이기 위해 `whisper.cpp`를 1순위로 둔다.

```bash
cd ~/safeaid_ai/stt
git clone https://github.com/ggerganov/whisper.cpp
cd whisper.cpp
cmake -B build -DGGML_CUDA=1
cmake --build build -j --config Release
bash ./models/download-ggml-model.sh small
```

테스트용 wav 변환:

```bash
ffmpeg -i ~/safeaid_ai/samples/mic_test.wav -ar 16000 -ac 1 ~/safeaid_ai/samples/mic16k.wav
```

한국어 받아쓰기:

```bash
time ./build/bin/whisper-cli -m models/ggml-small.bin -l ko -f ~/safeaid_ai/samples/mic16k.wav
```

실행 중 `jtop`에서 GPU 사용률 또는 `tegrastats`의 `GR3D_FREQ` 변화를 확인한다.

## 경로 B: faster-whisper (대안)

Python 통합은 편하지만 Jetson CUDA 휠 호환을 맞춰야 한다.

```bash
source ~/safeaid_ai/venv/bin/activate
pip install faster-whisper
```

```python
# ~/safeaid_ai/stt/stt_test.py
import time
from faster_whisper import WhisperModel

model = WhisperModel("small", device="cuda", compute_type="float16")

t0 = time.time()
segments, info = model.transcribe("../samples/mic16k.wav", language="ko")
text = "".join(s.text for s in segments)
print("TEXT:", text)
print("SEC :", round(time.time() - t0, 2))
```

```bash
cd ~/safeaid_ai/stt
python stt_test.py
```

CUDA 에러가 나면 일단 `device="cpu", compute_type="int8"`로 기능 확인은 할 수 있다. 하지만 최종 데모 경로는 GPU 가속 기준으로 다시 맞춘다.

## 실제 발화 테스트

| # | 발화 | 받아써야 할 핵심어 | 다음 단계 |
| --- | --- | --- | --- |
| 1 | "피가 나" | 피 / 출혈 | 응급 분류 |
| 2 | "손을 베였어" | 손 / 베임 | 응급 분류 |
| 3 | "물에 데었어" | 데임 / 화상 | 응급 분류 |
| 4 | "유리가 박혔어" | 유리 / 박힘 | 응급 분류 |
| 5 | "후시딘 있어?" | 후시딘 | 재고 검색 |
| 6 | "밴드 어디 있어?" | 밴드 | 재고 검색 |

주의: "후시딘 있어?" 같은 문장은 응급 시나리오 분류가 아니라 **재고 검색 경로**로 보내야 한다. STT 단계에서는 텍스트가 정확히 나오는지만 본다.
