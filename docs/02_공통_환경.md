# 2단계 준비: 공통 환경

목표: STT, LLM, 비전 테스트가 공유할 작업 폴더, Python 가상환경, 모니터링 도구, 측정 규칙을 만든다.

## 1. 작업 폴더 구조

```bash
mkdir -p ~/safeaid_ai/{stt,llm,vision,samples,results}
cd ~/safeaid_ai
```

| 폴더 | 용도 |
| --- | --- |
| `stt/` | Whisper 관련 빌드/스크립트/모델 |
| `llm/` | Ollama/llama.cpp 분류 테스트 |
| `vision/` | 비전 휴리스틱 검증 또는 TensorRT 모델 |
| `samples/` | 테스트용 음성/이미지 샘플 |
| `results/` | 측정 결과, 버전 기록 |

## 2. jtop 설치

Jetson에서는 `nvidia-smi` 대신 `jtop`과 `tegrastats`를 사용한다.

```bash
sudo pip3 install -U jetson-stats
sudo systemctl restart jetson_stats.service
sudo reboot
```

재부팅 후:

```bash
jtop
```

측정 중 볼 항목:

- GPU 사용률
- RAM/SWAP 사용량
- 온도와 쓰로틀링
- 전력 모드
- CPU 사용률

모델이 GPU를 쓴다고 가정하지 말고, **각 단계 실행 중 jtop에서 실제로 확인**한다.

## 3. Python 가상환경

JetPack은 CUDA/TensorRT/PyTorch 관련 패키지가 시스템 Python과 얽히는 경우가 많다. 가상환경은 `--system-site-packages`로 만든다.

```bash
cd ~/safeaid_ai
python3 -m venv venv --system-site-packages
source venv/bin/activate
python -m pip install -U pip wheel
```

매 세션 시작 시:

```bash
source ~/safeaid_ai/venv/bin/activate
```

## 4. 장치 점검

### 마이크

```bash
sudo apt install -y alsa-utils
arecord -l
arecord -d 5 -f cd ~/safeaid_ai/samples/mic_test.wav
aplay ~/safeaid_ai/samples/mic_test.wav
```

### 카메라

```bash
sudo apt install -y v4l-utils
ls /dev/video*
v4l2-ctl --list-devices
```

카메라가 안 잡히면 비전 단계보다 USB 전원, 케이블, 권한 문제를 먼저 해결한다.

## 6. 공통 측정 규칙

- 각 테스트는 **콜드 런 1회 + 웜 런 2회 이상**으로 기록한다.
- 기록 항목: 모델 로딩 시간, 추론 시간, RAM/SWAP 피크, GPU 사용 여부, 온도, 실패 로그.
- 측정 직전 `sudo jetson_clocks` 적용 여부를 확인한다.
- 네트워크 없이 동작해야 하는 모델은 설치 후 반드시 오프라인 테스트를 한다.
