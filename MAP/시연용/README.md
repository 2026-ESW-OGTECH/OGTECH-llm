# 시연용 지도 화면 — 7인치 1024×600

시연 영상 촬영과 UI 검토를 위한 **제품 화면**이다. 같은 폴더 위 `MAP/static/`은 지도 변환·GPS
연결을 확인하는 **개발자 도구**이고, 이쪽은 사용자가 산에서 실제로 보는 화면이다.

하드웨어와 백엔드 없이 혼자 돈다. 촬영 일정이 하드웨어 완성에 묶이지 않게 하려는 것이다.

관련 문서: [AGENTS.md](../../../AGENTS.md) 6절 UI 규칙 · [plan_08_10_demo_video.md](../../../plan_08_10_demo_video.md) 컷 3·4·5

---

## 실행

파일을 그대로 열어도 되고,

```
smartaid-llm/MAP/시연용/index.html
```

로컬 서버로 띄워도 된다. 외부 네트워크는 어느 쪽도 쓰지 않는다.

```bash
cd smartaid-llm/MAP/시연용
python -m http.server 8791 --bind 127.0.0.1
```

Jetson kiosk에서는 화면이 정확히 1024×600이라 여백 없이 꽉 찬다. 개발 PC에서는 검은 배경
가운데에 1024×600 화면이 실기와 같은 크기로 놓이고, 오른쪽에 촬영 보조 패널이 붙는다.
**보조 패널은 장치 UI가 아니다.** `H`로 숨긴다.

## 촬영 장면 — 숫자키

| 키 | 장면 | 대응 컷 | 보여 주는 것 |
|---:|---|---|---|
| `1` | 기본 | — | 현재 위치 + 정확도 반경. 글랜서블 4개 |
| `2` | 목적지 지정 | **컷 3** | 코드가 계산한 경로, `±m` 배지 |
| `3` | 일조 시간 경고 | **컷 4** | 적색 배너. 사용자가 묻지 않았는데 장치가 먼저 말함 |
| `4` | 베이스캠프 역추적 | **컷 5** | 저장 지점까지 방위·거리 |
| `5` | 트레일 이탈 | — | 이탈 거리 경고 |
| `6` | GPS 미수신 | — | 마지막 확정 좌표 + 경과 시간. 추정으로 덮지 않음 |
| `W` | 보행 재생 시작·정지 | **컷 3** | 마커가 경로를 따라 이동, 남은 거리 감소 |
| `N` | 야간 모드 | — | 적색 단색 |
| `H` | 보조 패널 숨기기 | 촬영 시 필수 | |

### `W` 는 측위가 아니다

Air530 이 도착 전이라 현재 위치가 실시간으로 갱신되지 않는다. `W` 는 **계산된 경로 위를
보행 속도(1.3 m/s)로 지나가는 합성 궤적**이며 GPS 신호가 아니다. 그래서

- `DEMO` 배지를 계속 띄운다 (안전 계약 8)
- 정확도·위성 수는 장면에 적힌 고정값을 그대로 쓴다. **그럴듯하게 흔들지 않는다**
- 방위·거리는 움직이는 좌표로 매번 다시 계산한다. 이 부분은 실제 코드 경로 그대로다

GPS 가 도착하면 이 재생을 **실측 트랙 재생**으로 교체한다. 그때 화면 코드는 바뀌지 않는다 —
좌표가 어디서 오는지만 달라진다.

화면 아래 버튼으로도 목적지·베이스캠프·야간 모드를 전환할 수 있다. 손으로 조작하는 그림을
찍을 때 쓴다.

## 설계 근거

### 물리 스케일 — 7인치에서 px는 거짓말이다

1024×600을 7인치에 넣으면 169.5 PPI, **1mm = 6.675px**이다.

| 요소 | 크기 | 물리 크기 | 판정 |
|---|---:|---:|---|
| 하단 동작 버튼 | 96px | 14.4mm | 주요 동작 기준 충족 |
| 본문 텍스트 | 20px | 3.0mm | 하한 |
| 글랜서블 값 | 30px | 4.5mm | 1초 판독용 |
| 스텐실 라벨 | 15px | 2.2mm | 라벨 전용. 본문에 쓰지 않음 |

상단 계기 스트립은 **읽기 전용**이라 터치 규격 예외다. 긴급 경로가 상단바 탭에 들어가면 안 된다.

### 색 규율

| 색 | 의미 | 이 화면에서 |
|---|---|---|
| 적색 | 경고 — 즉시 행동 | 일조 시간 부족, 트레일 이탈 배너 **여기만** |
| 앰버 | 주의 · 기본 액션 | 하단 버튼, `DEMO`, 베이스캠프 마커 |
| 녹색 | 실제 센서로 확인됨 | GPS fix, 정확도 반경, `OFFLINE` 태그, `코드 계산` 배지 |
| 시안 | 계측 판독값 | 방위, 거리, 남은 시간, 배터리 일수, 경로선 |
| 회색 | 데이터 없음 | GPS 미수신, 트레일 확인 불가 |

**회색이 녹색을 빌려 쓰지 않는다.** 장면 `6`이 그 규율을 보여 주기 위한 장면이다. 측위가
없으면 마커도 회색이고 방위·거리는 `—`로 남는다.

### 성능

Chromium이 llama-server와 GPU·통합 메모리를 나눠 쓴다.

- `backdrop-filter`, 큰 blur 그림자, `filter()` 없음. 깊이는 1px 하드 라인 + inset 하이라이트로만
- 애니메이션은 경고 배너의 18px 점멸 사각형 하나뿐. `opacity`만 바꾼다
- 외부 폰트·CDN·프레임워크 없음. 캔버스 직접 렌더링
- 상태를 상시 폴링하지 않는다. 장면 전환 때만 다시 그린다

## 안전 계약이 이 화면에 건 제약

1. **방위·거리·경로는 `app.js`가 계산한다.** LLM이 만들지 않는다. 화면의 `코드 계산` 배지가
   그 사실을 사용자에게 알린다. 영상 자막에 `AI가 길을 알려줍니다`라고 쓰면 안 된다
4. **GPS 미수신을 위치 추정으로 덮지 않는다.** 장면 `6`에서 마지막 확정 좌표와 경과 시간만
   표시하고, 방위·거리는 계산하지 않는다. 정확도와 위성 수는 항상 같이 표시한다
8. **`DEMO` 배지를 숨기지 않는다.** 이 화면의 좌표·센서·시간은 전부 고정 모의값이다.
   실제 센서로 바뀌기 전까지 이 배지는 코드에서 제거하지 않는다

## 지도 데이터 — 실제 건국대 캠퍼스

`konkuk_map.js`가 화면이 쓰는 데이터다. `sample_data/konkuk_walk.graphml`(OSMnx 보행망,
933노드 / 2668엣지)을 `build_map_data.py`가 한 번 변환해 구운 정적 파일이다.

```bash
cd smartaid-llm/MAP
.venv/Scripts/python.exe 시연용/build_map_data.py     # Windows
.venv/bin/python 시연용/build_map_data.py             # Jetson
```

| 항목 | 값 |
|---|---|
| 표시 범위 | **603 m × 247 m** (종횡비 2.44 = 캔버스와 동일) |
| 그리는 보행로 | 269개 폴리라인 |
| 파일 크기 | 17 KB |
| 목적지 | 경로 따라 **177 m** · 직선 151 m |
| 베이스캠프 | 경로 따라 **354 m** · 직선 257 m |

**서버가 필요 없다.** 촬영 일정이 백엔드 기동에 묶이지 않게 미리 구웠다.

### 왜 캠퍼스 전체를 넣지 않았나

두 가지 때문이다.

1. **종횡비.** 캠퍼스 전체 범위는 0.74(세로형)라 2.44 캔버스에 넣으면 지도가 화면 가운데
   좁은 세로 띠로 갇힌다. 억지로 가로를 늘리면 1.6 km짜리 창이 나온다
2. **판독성.** 전체를 넣으면 보행로가 실오라기처럼 가늘어져 7인치에서 읽히지 않는다

그래서 스크립트가 **시나리오 세 지점(현재·목적지·베이스캠프)을 감싸는 창을 잡고
캔버스 종횡비에 맞춰 확장**한다. 목적지는 동쪽, 베이스캠프는 서쪽으로 고르는데, 두 지점이
남북으로 벌어지면 창이 세로형이 되어 같은 문제가 되풀이되기 때문이다.

`build_map_data.py`의 `DESTINATION_TARGET_M` / `BASECAMP_TARGET_M`을 바꾸면 창 크기가
따라 바뀐다. 실제 촬영 장소가 정해지면 그 좌표로 지점을 고정하면 된다.

### 경로는 여기서도 코드가 계산한다

`build_map_data.py`가 `map_engine.find_route`(A*)를 호출해 실제 보행망 위의 경로를 뽑는다.
화면 JS는 그 결과를 그리기만 하고, 방위·거리는 haversine으로 다시 계산해 표시한다.
어느 단계에도 LLM이 없다.

### 백엔드 폴백

`konkuk_map.js`가 없을 때만 `/api/map`(포트 8790)을 찾고, 그것도 없으면 `app.js` 안의
가상 언덕 데이터로 돌아간다. 화면 배치만 검토할 때 쓰는 폴백이다.
